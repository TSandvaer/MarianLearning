# Phase 4: Playwright spec sort (invariants vs web-only)

**Scope:** React Native migration Phase 4, second bullet (`design/react-native-migration-plan.md` § Phase 4). The PWA retires once Marian is on the native app (`team/DECISIONS.md` 2026-10-12, "Native-only: the PWA retires at Phase 5"), and the web Playwright suite goes with it. This sort decides which spec behaviour must live on in Maestro, core or native jest tests.

**Base:** `origin/main` at `7c11a56`. There are 67 specs in `e2e/*.spec.ts` (the plan's figure of 71 is out of date). Every spec was read; none was run.

## How to read the table

- **Kind:** _Invariant_ is product behaviour Marian depends on. _Web-only_ is a browser mechanic (WebAudio, Howler unlock, service worker, page visibility, cross-tab storage, URL flags, DOM-only tooling).
- **Target:** _Maestro_ (an on-device flow), _core_ (Vitest in `packages/core`, or the `api/` and `scripts/` Vitest for canon and planner checks, which stay with the Vercel backend), or _native jest_ (`mobile/src`).
- **Already covered?** _Yes_, _Partial_ or _No_, with the test file and test name from a grep of the current tree. Paths are shortened: `core/` is `packages/core/src/`, `mobile/` is `mobile/src/`. `describe` means the cite is a describe block. The web Vitest suite under `src/` is deleted with the web front end, so a cite marked _(web, retires)_ is not lasting coverage.
- **Maestro (planned):** which of the four Phase 4 flows will exercise the invariant: **FL** first launch, **HMS** Hub → Math → Session End, **WS** Word Song, **MP** mastery promotion through a debug seed. Kevin's branch `kevin/rn-phase4-maestro` was not pushed when this was written, so this column follows the flow names in the plan, not the flows' actual steps.
