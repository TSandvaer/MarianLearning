## AC matrix

One row per AC bullet from `design/session-1.md` § "Screen 2 → Acceptance criteria" (spec lines 204–222 on `origin/main`), in spec order. Plus rows derived from Motion / States / Implementation Notes that the AC bullets compress (notably row 8 — first-utterance retry — and rows 21–24 covering Plan B's new contracts: pre-recorded MP3 integrity, offline precache, single-tap sufficiency, `last speak` overlay diagnostic gap).

**What changed in this revision (vs. the post-PR-#15 checklist):**

- **Row 4 (no audio pre-tap):** updated. Now asserts `Howl.play()` is not called pre-tap; the `speechSynthesis.speak` clause is removed (Plan B doesn't use Web Speech for Greet).
- **Row 7 (synchronous gesture-tied play):** updated. The synchronous handler now calls `playGreetLine('hi', ...)` inside the wake-tap, which in turn synchronously calls `howl.play()`. Latency target is the Howl `onplay` event firing within 250ms (was: `onstart` from `speechSynthesis`). Same iPad-Safari gesture-gate constraint.
- **Row 8 (first-utterance retry):** updated. Watchdog window is **1.5s**, not 5s. Howler's `onplay` reliably fires within ~50ms once gesture-unlocked, so 1.5s is plenty for cold-cache decode of the small (9–18 KB) MP3 files. Constant: `FIRST_UTTERANCE_RETRY_MS = 1_500`.
- **Row 11 (ear-wiggle on "Hi!"):** updated. Now driven by the linear word-tick timer (`onWordTick(0)`) on the pre-recorded engine, not Web Speech `onboundary`. Implementation routes `onWordTick` through the orchestrator's `onBoundary` callback (1:1 shape match), so the trigger code at the Greet.tsx level is unchanged.
- **Row 12 (caption sync):** updated. Captions are now driven by `howl.duration() / wordCount` linear timer, falling back to 165 wpm if `duration()` returns 0. The "165 wpm fallback" language still applies, but the primary path is duration-driven, not `onboundary`-driven.
- **DELETED rows from the prior checklist:** voice-selection picker, `pickMelodyVoice` logic, `getVoices()` race conditions, GBUG-6 (voice picker race) — all moot for pre-recorded audio. The voice is now hardcoded `en-US-AnaNeural` Cartoon/Cute, embedded in the MP3s, and was Thomas-approved.
- **NEW rows:** 21 (debug-overlay `last speak` gap), 22 (MP3 file integrity at runtime), 23 (offline precache), 24 (single tap is sufficient — i.e. no need for multi-tap-to-warm-up the engine).
